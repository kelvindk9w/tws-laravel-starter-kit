# Código de conduta

Este projeto quer ser um lugar acolhedor para qualquer pessoa, independente
de experiência, identidade, origem, aparência, deficiência, idade, religião
ou orientação. O texto abaixo segue o espírito do
[Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## O que se espera

- Respeito nas issues, nos pull requests, nas discussões e em qualquer
  espaço do projeto.
- Crítica ao código e às ideias, nunca às pessoas.
- Paciência com quem está começando: o kit foi feito também para iniciantes.
- Assumir boa-fé e pedir esclarecimento antes de concluir.

## O que não é aceito

- Ofensa, assédio, ataque pessoal ou linguagem discriminatória.
- Exposição de dados pessoais de alguém sem permissão.
- Insistência depois de um pedido claro para parar.
- Divulgar publicamente uma vulnerabilidade antes da correção (ver
  [SECURITY.md](SECURITY.md)).

## Como reportar

Escreva para **kelvindk9@gmail.com** com "[conduta] tws-laravel-starter-kit"
no assunto. Todo relato é lido e tratado com sigilo.

## Consequências

O mantenedor pode editar ou apagar comentários, fechar issues e pull
requests e bloquear, temporária ou definitivamente, quem descumprir este
código — proporcional ao caso, depois de ouvir as partes quando possível.

---

# Code of conduct (English)

Be respectful, criticise code and ideas rather than people, and be patient
with newcomers. Harassment, personal attacks, discriminatory language and
publishing other people's private data are not tolerated. Report incidents to
**kelvindk9@gmail.com** with "[conduct] tws-laravel-starter-kit" in the
subject; reports are handled confidentially. Inspired by the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
