# Pacotes do kit

Pasta reservada para os pacotes reutilizáveis do kit (segurança e
infraestrutura, autenticação, contas e API, uploads e o painel de
administração). Ela está vazia de propósito: cada pacote é extraído do
aplicativo em `starters/livewire` numa fase própria, com a suíte de testes
verde antes e depois, e só então aparece aqui.

Até lá, todo o código do kit vive em [`starters/livewire`](../starters/livewire).
